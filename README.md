# Unit Converter

A simple Unit Converter built using HTML, CSS, and JavaScript.

## Features
- Convert length units
- Convert weight units
- Live unit conversion
- Swap units easily
- Simple and user-friendly design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Use
1. Select Length or Weight.
2. Enter a value.
3. Select the From and To units.
4. View the converted result.
5. Click Swap Units to reverse the conversion.
